# OpenFatture v2.0.1

**Release date:** 7 August 2026  
**Status:** Patch on 2.0.0

## Highlights

- **Status readiness** — `openfatture status` and `--json` expose `readiness`
  (`core_ready`, `assistant_ready`, checks, `next_steps`).
- **Interactive slash commands** — `/help`, `/exit`, `/session`, `/clear`
  in multi-turn assistant sessions.
- **Safer init** — no silent overwrite of existing `.env`; dirs/database still
  ensured when config is preserved.
- **Registry package** — `openfatture.ai.tools.registry` split into
  `core` / `defaults` without changing public imports
  (`ToolRegistry`, `get_tool_registry`).
- **LangGraph parity tests** — product backend remains ChatAgent tool loop
  (B1-β); helper graph covered by contract tests.

## Upgrade

```bash
uv sync
# or with AI:
uv sync --extra ai
openfatture status --json
```

No breaking import changes from 2.0.0.
