# OpenFatture v1.2.0 – Event System and Audit Trail

**Release date:** 2 December 2025
**Status:** Stable

## Highlights

- Persistent event log with entity tracking, metadata, timelines, and search.
- Event statistics, analytics, trends, and terminal dashboards.
- Expanded payment, AI, batch, quote, and Lightning workflows.
- CLI-first documentation and interactive terminal workflows.

## Upgrade notes

Run the test suite after updating dependencies and review local configuration
against `docs/CONFIGURATION.md`. The current application version is exposed by
`openfatture --version` and `openfatture.__version__`.

## Validation

```bash
uv sync --all-extras
uv run python -m pytest
uv run openfatture --version
```
