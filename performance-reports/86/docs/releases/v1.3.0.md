# OpenFatture v1.3.0

**Release date:** 24 July 2026
**Status:** Stable

## Highlights

- Reduced the public CLI to the agentic assistant, interactive session, setup,
  configuration, and status commands.
- Removed obsolete web UI and provider-dependent media automation surfaces.
- Preserved payment, Lightning, SDI, AI, and plugin capabilities as core or
  extension modules rather than public command groups.
- Added a deterministic, provider-free CLI demo and CI validation workflow.
- Modernized Make, Docker Compose, Alembic, pre-commit, MyPy, and GitHub Actions
  configuration for the 2026 toolchain.
